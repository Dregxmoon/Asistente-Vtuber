Kaoru

Un asistente personal de escritorio con voz, memoria e integración opcional con Google Workspace.

Aviso de Privacidad Términos de Servicio Código en GitHub

¿Qué es Kaoru?

Kaoru es una aplicación de escritorio (Windows, macOS, Linux) que actúa como asistente personal: responde por voz y texto, recuerda contexto entre conversaciones, y puede actuar como agente sobre tu propio equipo — editar archivos, ejecutar comandos, trabajar con Git/GitHub — siempre bajo el nivel de autonomía y las reglas de permiso que tú configures (Observar / Sugerir / Actuar).

Cómo funciona por dentro

ComponenteCómo funciona
Conversación (LLM)Tú eliges y conectas con tu propia clave de API. Trae integrados Groq, Google Gemini, OpenAI, Anthropic, xAI, NVIDIA, Hugging Face y DeepSeek, con reintento y cambio automático entre ellos si uno falla. Con el comando /provider add puedes sumar cualquier otro proveedor compatible con la API de OpenAI, incluyendo un modelo local en tu propio equipo (Ollama, LM Studio, etc.).
Reconocimiento de voz (STT)100% local y sin conexión, con el motor Vosk. Tu voz no sale de tu equipo para ser transcrita.
Síntesis de voz (TTS)Usa el servicio en la nube de Microsoft Edge (edge-tts) para generar el audio de lo que Kaoru te dice.
MemoriaGrafo de memoria local (hechos, episodios de conversación, creencias inferidas con tu aprobación) en una base de datos SQLite en tu equipo, con búsqueda por significado 100% local y decaimiento automático de lo antiguo.
ProactividadKaoru puede tomar la iniciativa y hablarte primero según patrones que detecta (foco prolongado, errores de código, recordatorios próximos, etc.), siempre con un filtro determinista de "buen momento" y pidiendo tu confirmación antes de ejecutar cualquier acción real.
Google Workspace (opcional)Tú conectas tu propia cuenta con tu propio proyecto de Google Cloud. Puedes elegir qué servicios activar (Calendar, Gmail, Drive, Docs, Sheets, Tasks, Contactos) y si el acceso es solo lectura o también escritura.
CredencialesTus claves de API y tokens se guardan cifrados en el almacén de credenciales de tu sistema operativo (Keychain / Credential Manager / Secret Service), nunca en un servidor de Dregxmoon.

Kaoru no opera ningún servidor central que reciba tus datos: todo corre en tu equipo, salvo las conexiones que tú mismo autorizas hacia Google, tu proveedor de IA, o el servicio de voz. El detalle completo de qué se comparte y con quién está en el Aviso de Privacidad.

Modo agente

Además de responder, Kaoru puede tomar acciones concretas cuando se lo permites: editar y crear archivos, ejecutar comandos de terminal, trabajar con repositorios Git y GitHub, y navegar la web con un navegador automatizado independiente. Tú controlas cuánta autonomía le das, desde solo observar hasta actuar automáticamente bajo reglas que tú mismo defines. Ver detalle en los Términos de Servicio.
